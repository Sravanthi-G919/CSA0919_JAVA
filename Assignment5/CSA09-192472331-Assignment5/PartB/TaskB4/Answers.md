# Task B4 – Final engineering decision
`PassFileMigration` validates five-field records, reports invalid rows to `migration-failures.txt`, and loads valid rows in batches in a transaction. Run `DatabaseMetadataReport` to report database product/version, JDBC driver version and tables.
For 12 campuses, concurrent issuing counters, shared searching and transactional safety, a central relational database is the recommended production design. Text files are simple but do not provide safe concurrent updates or efficient shared queries; Java serialization is Java-specific and not suitable as the shared multi-writer store. Use appropriate indexes, unique constraints, transactions, backups, access control and campus-aware identifiers.
If each campus had a separate serialized file, searches may need to inspect all 12 files (O(total records) without indexes), data is duplicated/fragmented, and conflict reconciliation is needed. A shared database centralizes concurrency control and search.
