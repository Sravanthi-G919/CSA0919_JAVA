Use JDK 8 or later. Compile and run from each task folder, for example:
`javac FeeWindow.java`
`java FeeWindow`

**Important:** GUI programs require a desktop Java environment that supports AWT/Swing windows. Many online Java compilers cannot display GUI windows. Use VS Code with a JDK or another desktop Java IDE for GUI execution. Screenshots must be captured by you after running the programs.
